# 🍪 Печенько-кликер

**Заразная игра-кликер** на React + Vite: нажимайте на печенье, покупайте постройки с пассивным доходом и улучшайте силу клика. Цель — испечь как можно больше печенья! 

> ℹ️ История проекта: изначально здесь был веб-мессенджер (React + Node.js + Socket.IO) — его код можно найти в [ранних коммитах](https://github.com/belknikolja-arch/messenger/commits/main/). Затем проект превратился в игру.

## ✨ Возможности

- 🍪 **Кликай и пеки** — большая печенька с анимациями и всплывающими «+N»
- 🏭 **7 построек** — от Курсора до Портала в другие миры (пассивный доход)
- ⬆️ **Улучшения клика** — множители силы нажатия до ×96
- 📈 **Растущие цены** — каждая постройка дорожает на 15%
- 💾 **Автосохранение** — прогресс хранится в localStorage
- 🌙 **Офлайн-доход** — построки «работают» без вас до 8 часов
- 🌙 **Тёмная тема** и адаптивная вёрстка (десктоп + мобильные)
- 🔢 **Красивые числа** — тысячи, миллионы и триллионы в компактном виде

## 🛠 Технологии

| Слой | Стек |
| --- | --- |
| Клиент (вся игра) | [React 18](https://react.dev), [Vite](https://vitejs.dev) |
| Сервер (раздача статики) | Node.js, [Express](https://expressjs.com) |

Игра полностью работает в браузере — сервер нужен только для хостинга статики.

## 🚀 Быстрый старт

> Требуется Node.js **18+**.

```bash
# 1. Установить зависимости
npm run setup

# 2. Запустить (клиент + сервер)
npm run dev
```

Игра откроется на **http://localhost:5173**.

## 📦 Продакшен-режим

```bash
npm run setup
npm run build   # сборка клиента в client/dist
npm start       # Express отдаёт игру на одном порту
```

## 🎮 Как играть

1. **Кликайте по печенью** — каждое нажатие печёт печенье
2. **Покупайте постройки** в магазине справа — они пекут печенье сами, каждую секунду
3. **Улучшайте клик** — множители ускоряют каждое нажатие
4. Комбинируйте: постройки дают стабильный доход, улучшения — мощные разовые бонусы

## ☁️ Деплой — постоянная ссылка

### Render (бесплатно, один клик)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/belknikolja-arch/messenger)

1. Войдите через GitHub-аккаунт (карта не нужна) и нажмите **Apply**.
2. Через 2–3 минуты игра получит постоянный адрес вида `https://cookie-clicker-xxxx.onrender.com`.

> На бесплатном тарифе сервис «засыпает» после 15 минут без посетителей — первое открытие после паузы занимает до минуты.

### Docker / другие платформы

```bash
docker build -t cookie-clicker .
docker run -p 80:3001 cookie-clicker   # порт задаётся переменной окружения PORT
```

| Параметр | Значение |
| --- | --- |
| Build command | `npm run setup && npm run build` |
| Start command | `npm start` |
| Порт | из переменной окружения `PORT` |
