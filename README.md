# 🍪 Печенько-кликер

**Заразная игра-кликер** на React + Vite: нажимайте на печенье, покупайте постройки с пассивным доходом и улучшайте силу клика. Цель — испечь как можно больше печенья!

**🎮 Играть онлайн (постоянная ссылка):** **[belknikolja-arch.github.io/clicker](https://belknikolja-arch.github.io/clicker/)**

> Игра развернута на **GitHub Pages** и обновляется автоматически при каждом изменении кода. Прогресс хранится в браузере.

> ℹ️ История проекта: изначально здесь был веб-мессенджер (React + Node.js + Socket.IO) — его код можно найти в [ранних коммитах](https://github.com/belknikolja-arch/clicker/commits/main/). Затем проект превратился в игру.

## ✨ Возможности

- 🍪 **Кликай и пеки** — большая печенька с анимациями и всплывающими «+N»
- 🏭 **7 построек** — от Курсора до Портала в другие миры (пассивный доход)
- ⬆️ **Улучшения клика** — множители силы нажатия до ×48
- 📈 **Растущие цены** — каждая постройка дорожает на 15%
- 💾 **Автосохранение** — прогресс хранится в localStorage
- 🌙 **Офлайн-доход** — постройки «работают» без вас до 8 часов
- 🌙 **Тёмная тема** и адаптивная вёрстка (десктоп + мобильные)
- 🔢 **Красивые числа** — тысячи, миллионы и триллионы в компактном виде

## 🛠 Технологии

| Слой | Стек |
| --- | --- |
| Клиент (вся игра) | [React 18](https://react.dev), [Vite](https://vitejs.dev) |
| Хостинг | [GitHub Pages](https://pages.github.com) + GitHub Actions |
| Сервер (опционально) | Node.js, [Express](https://expressjs.com) — раздача статики |

Игра полностью работает в браузере — интернет нужен только для загрузки страницы.

## 🚀 Запуск локально

> Требуется Node.js **18+**.

```bash
# 1. Установить зависимости
npm run setup

# 2. Запустить (клиент + сервер)
npm run dev
```

Игра откроется на **http://localhost:5173**.

## 🎮 Как играть

1. **Кликайте по печенью** — каждое нажатие печёт печенье
2. **Покупайте постройки** в магазине справа — они пекут печенье сами, каждую секунду
3. **Улучшайте клик** — множители ускоряют каждое нажатие
4. Комбинируйте: постройки дают стабильный доход, улучшения — мощные разовые бонусы

## ☁️ Деплой

**GitHub Pages (основной способ)** — уже настроено: при пуше в `main` GitHub Actions сам собирает игру и публикует её на [belknikolja-arch.github.io/clicker](https://belknikolja-arch.github.io/clicker/). Ничего делать не нужно.

**Альтернативы** (если нужен свой домен или сервер):

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/belknikolja-arch/clicker)

```bash
docker build -t cookie-clicker .
docker run -p 80:3001 cookie-clicker   # порт задаётся переменной окружения PORT
```

| Параметр | Значение |
| --- | --- |
| Build command | `npm run setup && npm run build` |
| Start command | `npm start` |
| Порт | из переменной окружения `PORT` |
